# Photo Website Sample

A responsive photography portfolio website with categorized galleries, lazy-loaded images, direct WhatsApp booking, call actions, and editable studio details.

## Preview locally

```bash
python3 -m http.server 8000
```

Open <http://localhost:8000>.

## Update business details

```bash
python3 update_site.py --studio "My Studio" --phone "+919999999999" --address "My address"
```

## Rebuild galleries

```bash
python3 build_gallery.py
```
